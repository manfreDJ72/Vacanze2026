## ⚠️ SETUP IN 3 PASSI (leggi prima di tutto)

### Passo 1 — Rinomina il file principale
Il file si chiama `index.html` — assicurati che sia esattamente così nel repository, non `vacanze2026.html`.

### Passo 2 — Attiva GitHub Pages
1. Vai su **Settings** del repository
2. Clicca **Pages** nel menu a sinistra
3. Source: **Deploy from a branch**
4. Branch: **main** → cartella **/ (root)**
5. Clicca **Save**
6. Aspetta 2 minuti, poi vai su `https://manfredj72.github.io/Vacanze2026/`

### Passo 3 — Carica le foto della villa 📸
Le foto di Airbnb vengono bloccate se caricate da altri siti. Devi scaricarle e caricarle tu:

**Come scaricare le foto:**
1. Vai su https://www.airbnb.it/rooms/9536949
2. Clicca su ogni foto → tasto destro del mouse → **"Salva immagine come..."**
3. Scaricale tutte (sono circa 8–10)

**Come caricarle su GitHub:**
1. Nel repository, clicca **Add file** → **Create new file**
2. Scrivi il nome: `img/piscina.jpg` (questo crea automaticamente la cartella `img/`)
3. Trascina la foto nel campo che appare
4. Ripeti per ogni foto con questi nomi:

| Nome file | Foto da scaricare |
|-----------|-------------------|
| `img/piscina.jpg` | La foto principale con piscina |
| `img/giardino.jpg` | Il giardino con gli ulivi |
| `img/living.jpg` | La zona living/veranda |
| `img/esterno.jpg` | L'esterno della villa |
| `img/camera1.jpg` | Camera matrimoniale piano terra |
| `img/camera2.jpg` | Camera vista piscina |
| `img/camera3.jpg` | Camera doppia primo piano |
| `img/camera4.jpg` | Altra camera doppia |
| `img/camera5.jpg` | Camera matrimoniale primo piano |
| `img/dependance.jpg` | La dependance |

> **Nota:** Se non carichi le foto, la pagina funziona lo stesso ma mostra uno sfondo blu al posto delle immagini. Le foto della villa vengono mostrate comunque quando gli utenti aprono il link Airbnb.
